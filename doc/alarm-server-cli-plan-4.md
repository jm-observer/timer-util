# Plan 4: 配置、输出与错误处理

## 目标

定义 CLI 的服务端地址配置方式、输出原则和错误处理方式。

## 需求

### 1. 服务端地址配置

CLI 需要支持以下配置方式：

- `--server <url>`
- 环境变量 `ALARM_SERVER_URL`

优先级：

- `--server` 高于 `ALARM_SERVER_URL`
- `ALARM_SERVER_URL` 高于默认值

默认值：

```text
http://127.0.0.1:8080
```

### 2. 输出要求

- 默认输出 JSON
- 成功时输出服务端返回体
- 不增加默认表格渲染
- 不要求彩色输出

### 3. 错误处理

错误场景包括：

- 本地参数缺失
- 本地参数格式错误
- 服务端不可达
- 服务端返回 4xx
- 服务端返回 5xx
- 返回体非预期

处理要求：

- 优先暴露服务端原始错误语义
- 本地参数问题与远端调用问题需要可区分
- 不构建复杂错误分类体系

### 4. 与服务端关系

- CLI 不新增服务端 API
- CLI 不修改服务端响应结构
- CLI 以现有 `/api/alarms` 和 `/api/alarms/{id}` 为基础

## 验收

- 服务端地址来源明确
- 默认输出策略明确
- 错误处理原则明确
